# URL blocklist
#
# Checked against the FULL url of any reference link before that link is
# allowed to leave a device in a community pack, and again by the moderation
# Action on the pull request. One term per line, lower case. Blank lines and
# lines starting with # are ignored. Matching is substring, case-insensitive,
# against the whole url including the domain, the path and the query.
#
# This is deliberately owner-tweakable, like moderation/blocklist.txt beside
# it. Add to it freely; that is what it is for.
#
# WHAT THIS CAN AND CANNOT DO
# ---------------------------
# It reads the address. It cannot read the page. A clean-looking url can point
# anywhere, and a shortener hides the destination entirely — which is why the
# shortener domains below are blocked outright rather than inspected.
#
# The app also never shows a raw address: a reader sees the label the
# contributor wrote and the bare domain underneath, so they can judge where
# they are about to go before they go there. The blocklist is the first gate,
# the domain line is the second, and the person tapping is the third.
